v1.0.2 — [2026-06-04] — Reconstrução dos endpoints /api/tab-order
----------------------------------------------------------------
Arquivo:  backend/app.py

          Perfil"), ao clicar "Salvar Permissões" o frontend chamava

          do SPA pegava a rota e devolvia 405 "Method Not Allowed".

Alterações (inseridas entre PUT /api/settings/tab-permissions e
GET /api/summary, ~linha 1549):

  GET /api/tab-order   (require_auth)
    - Retorna {"order": [...]} se houver ordem salva
    - Retorna {"order": null} se nunca foi configurada
              (frontend usa ordem default nesse caso)

  PUT /api/tab-order   (require_admin, async)
    - Body: JSON array de strings (ids das abas na nova ordem)
    - Usa `body = await request.json()` em vez de `body:list`
      — FastAPI não aceita JSON array diretamente como parâmetro
      `list`. Esse era o detalhe que causava o [object Object]:
      o erro de validação 422 vinha como array de objetos e virava
      "[object Object]" no toast do frontend.
    - Persiste em settings(key='tab_order', value=JSON)
    - Valida que é array e que itens são strings → 400 se inválido
    - Verifica pós-escrita → 500 se a gravação não confirmar
    - Retorna {"ok": True, "saved": [...]}

Padrão: espelha 100% o /api/settings/tab-permissions ao lado
(mesma tabela settings, mesmo DELETE+INSERT, mesma verificação).
